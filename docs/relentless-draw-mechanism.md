# Relentless 抽牌与 Warborne 高等级组合

固定游戏 2.3.1 / build 26650011，MVID
`bf93f060-beda-46b1-b808-95ebf1e9a99d`。
`RelicEffectAdditionalDrawDuringRelentless` 按初始化参数复用，没有来源 ID 白名单。

## 源码与模型

原生保存 `_cardsToDraw` 整数和 MutableRules 的浮点 Value。开局与抽牌前 Test
遍历普通楼层，查双方物理占位是否有正数 Relentless 状态；薪火层不参与。
找到即将 Value 设为初始化奖励，否则归零。两个 Test 都返回 false，不发牌、
不发显示信号，也不通知遗物触发。普通查询继续读取缓存，不能实时重算。

GetCharactersWithStatus 不筛除死亡、正在出生或已发出消失事件的角色；只要
角色还在物理组内且状态仍在，就可能命中。InSameRoom 在固定版本中直接返回
true。HasStatusEffect 按原生字典顺序取第一个忽略大小写的键，数量须大于零。
模型保留这些语义，物理引用移除后不再计入，不复用存活占层筛选。

开局使用原生 start-of-battle 的部署选择规则，普通抽牌前使用常规部署限制，
两者均沿用预演与条件过滤。抽牌前消费者按 owner／effect 顺序处理，与已有
满血抽牌共用管线，独立更新不可变缓存。会被当前管线提前执行的较晚治疗／升级／房间回调仍显式
拒绝，等待统一有序整合。初始化奖励的 int→float 精度变化、
Mathf.RoundToInt 和随后整数溢出／上下限均保留；Int32.MaxValue 转为 float 后
越过正整数边界，固定 Unity/Mono 的查询结果已独立校准。

## 原生校准

自动发现 WarborneT2/T3 两个原版来源，加八组数值控制，共 10 组配置、640 条
真实 Test 回调。覆盖两种 Test、两个陈旧缓存、四层 16 种状态组合，含只在
薪火层有状态的反例；负数、零、超过 float 精确整数范围及 Int32 两端都保留。
使用分离效果对象与独立 MutableRules 实例，控制房间状态查询，并检查原生
查询参数、提前结束、浮点缓存、false 返回、零显示信号及真实整数查询结果。

矩阵原生约 0.003 秒，不含启动。完整战斗、原版定义、RNG、帧与队列前后
一致。640 个不可变模型后继、16 路并行数值复验、双方／死亡／消失／出生中、
物理移除、状态大小写与首次匹配、部署／预演／开局选择、满血抽牌组合与复位
均通过。底层角色筛选的额外边界来自源码与模型控制，未把受控房间返回值
当作所有角色组合的原生实测。

## 两场整合

两场均在房间初始化前取得未改定义的原版灵魂。使用三个零费 80 攻击／5000
生命的 Steward、一个零费 200 敌方整层伤害法术；为敌方 MageT1_Junker 增加
Relentless 作为正例，保留其余参数。这些是机制控制，不计入原版卡牌覆盖。

- T2：4 次出牌、5 次 EndTurn、43 房间／9 列车阶段、136 完整上下文；隐藏
  静音 NativeWorker 3、Instant 原生胜局 78.00 秒。
- T3：另加六张零费、获得 1 能量的控制牌，同一回合执行 10 次出牌。
  原版第十次出牌条件实际抽到两张，复用已有通用出牌抽牌消费者；5 次
  EndTurn、40 房间／9 列车阶段、142 完整上下文，原生胜局 49.17 秒。

两场采集失败／差异／未支持／待完成四项为零。Relentless 正奖励及后续归零、
占层奖励随击杀更新、实际抽牌／RNG、连续整局、每场 16 条不可变分支、全部
录制决策候选、串并行根搜索及返回计划复放通过。合计 14 次出牌、10 次
EndTurn、83 房间／18 列车阶段、278 完整上下文。运行时间不是独占性能基准。

三个 `.mt2f` 合计 87,926 字节，由 SHA-256 清单固定，无 JSON 依赖。
入口支持日常只校准新机制；原版开局／满血抽牌、旧资源与占层抽牌定向回归
独立执行，不重跑全部归档。
