# 晚期攻击倍率的共用机制

固定游戏 2.3.1 / build 26650011，MVID
`bf93f060-beda-46b1-b808-95ebf1e9a99d`。
按 `RelicEffectMultiplyAttackLate` 的实现与参数适配，复用现有不可变攻击修饰器，
不为每张卡、遗物或变异器增加模型身份白名单。

## 规则与入口

- 参数为初始化后的 float 倍率、源阵营掩码及冠军豁免。
  原生判断为 **sourceTeam.HasFlag(characterTeam)**；与出生百分比的掩码方向不同。
- 遗物管理器按遗物／效果顺序相乘，最终攻击在原始攻击、增益、状态缓存、
  房间修饰和遗物额外攻击之后乘倍率，向上取整，再限制为非负数。
- 薪火的特殊规则来自原版 `ShouldSkipLateAttackMultiplierForPyre`：存在原版
  友军攻击减半变异器时跳过整个晚期倍率阶段。采集端捕获这个布尔结果，模型
  不按内容 ID 判断。出生百分比的攻击写回直接查询倍率，不使用薪火豁免。
- 固定攻击、护甲转攻击和生命转攻击沿用原生单位查询的提前返回。
  手牌显示另按 CardState 入口验证：固定攻击／生命转攻击提前返回，护甲转攻击
  仍受显示倍率影响；出生使用未缩放的原始定义。
- 活跃倍率下的单位 BaseAttack 保留未缩放原值，避免捕获后再乘一次；最终攻击
  在共享战斗、薪火查询、按攻击结算状态、攻血交换和百分比出生入口计算。

新增描述复用 `UnitModifiers.StatusAttackModifiers` 的所有既有复制路径；
`LateAttack == null` 保持原来的按状态加攻语义。每件遗物只捕获自己的有序效果，
单位携带整个管理器的有序提供者。缺参数、未知阵营、非有限倍率、附加条件或
缺冠军元数据保持拒绝。变异器仅在没有 Covenant、且全部为已捕获的无条件
百分比／晚期倍率效果时绕过旧的笼统保护。

## 一次原生进程内的批处理

八类目录扫描发现本版唯一原版定义 `Echoes_FriendlyUnitsHalfAttack`：
0.5 倍、Monsters、冠军豁免。根据同一实现生成十种倍率、四种源阵营、
两种豁免条件和四种目标阵营／冠军条件，共 **640 组查询**。
另有 **80 组有序叠乘** 和 **640 组实际 CharacterState 攻击查询**，覆盖
奇数、负数、状态攻击缓存、float 精度边界、整数极值、冠军和薪火。
负数／极值为数值控制，不主张它们全部为正常战斗可达状态。

管理器矩阵在结算空闲点同步临时替换隔离实例中该变异器的运行时效果列表；
原版定义不改写，finally 恢复原效果引用与顺序。攻击查询使用未注册的独立单位。
完整决策状态、原版字段、所检查 RNG、帧、空触发队列与效果引用还原均一致。
独立模型逐项比较，并做 16 路并行求值。该原生矩阵 **约 0.017 秒**。

同一原生进程复用百分比生成器：**138 组配置、7,728 组查询／出生回调对**，
这次包含非中性晚期倍率；独立检查也验证共享不可变单位写回。
上一份中性倍率归档保留，日常无需重新启动游戏。

## 原版整合与范围

两个原版变异器定义保持不变，组合“友军攻击减半”与“双倍敌方生命”。
Steward 是明确编写的 81 攻／5,000 血耐久控制，不计作原版卡牌覆盖。
实际单位的 BaseAttack／raw attack 为 81，计算攻击为 41；薪火保持原生豁免。

原生胜局四项失败计数为零，启动加连续战斗 **41.28 秒**。
独立检查匹配一次出牌、五次 EndTurn、43 个房间阶段、九个列车阶段、
130 份完整上下文及 16 条独立不可变分支。完整录制候选前沿零未支持，
串并行根搜索、返回计划复放一致；七只敌方正例的双倍生命仍成立。

证据仅使用二进制归档与哈希清单：
`tests/compatibility/game-2.3.1/mechanics/late-attack/manifest.tsv`。

```powershell
# 离线批量组件；不启动游戏

# 组件、整局、分支与搜索

# 需要重新生成原生证据时，隐藏、静音的隔离实例
```

这一组认证共用倍率与上述连续战斗接入。实际状态施加／撤销的各种交互、
所有其他遗物的组合、其他百分比变异器的伴随效果与 Covenant 混用未因此全部
认证；继续由对应机制及后续实际反例推进，不为每种参数重新录一场整局。

定向回归通过：上一组百分比原生矩阵与完整战斗；既有按状态加攻、薪火／
资源与触发状态纯检查；固定阶段中的 punished-units（25 次出牌／五次 EndTurn）。
未重新运行八项阶段全集或全部旧归档。
