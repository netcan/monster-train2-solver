# 原版友军失血光环的卡牌悬停预演

2026-11-15，游戏 2.3.1 / build 26650011，MVID
`bf93f060-beda-46b1-b808-95ebf1e9a99d`。

在[原版整局场景](room-health-attack.md)三来源刚叠加后，暂停输入，直接调用
原生 `CombatManager.PreviewCardPlay`。同一原版冠军的三个等级副本保留原版
1／2／3 系数升级、公共技能触发器和状态，另有两个受伤友军。其他楼层保留
原生敌人、控制友军与薪火；不修改原版冠军或升级定义。

## 一次批量验收

从五个同层目标生成单体输入，再生成来源层和其他层的整层输入。每组包括
3／9999 伤害、3／9999 治疗、3／9999 最大生命削减和 +3 最大生命，共 49 次。
伤害／治疗／最大生命机制和临时副本管线复用已有实现；样本不按模型预测筛选。

隐藏、静音 NativeWorker 3 共耗时 **57.14 秒**，包含启动、19 次场景输入及
49 个预演。原生组件完成，原玩家文件不变。组件采样不等于又录制一场胜局。

独立检查全部输入分支、复制前／临时效果后／取消后的完整列车状态、所有被复制
单位、分配器和上下文，逐样本做 16 次不可变模型求值。另比较 **1,446 次**
原生攻击查询，其中 280 次为普通受益者的正增益。明确数值见证包括：

- 五个目标各受三点伤害后，攻击均增加 18，来自三个来源系数之和六。
- 六个来源单独致死输入，将存活来源从三减为二；两个整层致死输入降至零。
- 整层完全治疗后，所有该层攻击恢复到没有缺失生命加成的值。
- 预演取消后，三位来源与所有主状态恢复；其他楼层的完整状态一致。

受检查的游戏 RNG 和 Unity RNG 保持一致；沿用已有检查器排除非确定性和
Chatter 流。触发队列为空，临时副本已关闭，预演抑制计数归还。两份原版定义
快照完全一致；原始副本分配器等原生保留状态按既有协议比较，未假定所有缓存回退。

## 放开的保护与范围

移除 FriendlyOwn 的整体悬停拒绝。普通无特性／无卡牌升级的伤害、治疗、
最大生命法术可经过原有 CardHoverPreview 管线，动态光环使用前一批共享规则。
公共技能来源 `UnitAbilityCommonData` 的自身技能激活、可用和不可用回调被识别
为普通手牌预演中的非活跃回调；49 次原生分派记录确认它们均未触发。保留这些
触发器的完整副本状态，仍拒绝活跃施放监听器与其他未经校准的生命周期。

本批使用普通控制法术和原版冠军载体，未驱动鼠标，不代表所有原版法术、技能
预演、选择召唤、移动预演、复杂卡牌特性／升级、附魔及遗物组合已完成。
不增加原版卡牌或遗物的整场覆盖数。原生预演只用于对照，不作为多回合搜索的
回退沙箱；并行求值运行在不可变模型上。

目录核对另确认系数二升级 `UnitUpgradeTitanSavageryAtkPerHP` 在当前 724 张卡
定义中没有引用，暂不优先为它编写原版卡整局场景。该结论不排除尚未审计的其他
生成入口，系数二升级生命周期也没有因此标为完成。
