# 剩余验收目标

截至 2026-10-25。当前已可在 Windows 使用，但自然对局的策略质量和任意组合支持
仍未全部验收。以下只列当前缺口；已完成的详细过程移至
[历次验收记录](acceptance-progress.md)，避免旧败局被反复当成新任务。

## 当前开发顺序

| 优先级 | 剩余目标 | 已知边界与完成条件 |
| --- | --- | --- |
| 1 | 自然 Covenant 3 第六战的默认策略 | 前五战已有原生胜局与独立重放；第六战双天使仍败。先离线找到并完整复演改进路线，再做实际默认预算的原生玩家胜局与独立重放。第七、八战在此之后继续。 |
| 2 | 复杂月相、遗物及嫁接组合 | 原始单卡/单遗物已有证据，组合仍可能触发精确签名保护。每批选一个实际未校准签名，补原生边界、不可变模型复演和受影响的玩家流程。 |
| 3 | 其他自然终局与更高 Covenant 的质量 | 已校准出生或受控战斗不等于自然默认预算能赢。按具体首领、牌组和预算分别取得源局与独立重放。 |
| 4 | 真终局自然解锁与自然通关 | 独立恢复的检查点不累加原生剧情指标，需保留一个隔离档案跨局推进并领取原生剧情奖励，再验收自然真终局。 |

用户已要求不再构建 Mac 包。Mac 实机加载、字体和交互仍属外部验收项，未计为已完成，
也不阻塞上述 Windows 开发。

## 覆盖与验证方式

[卡牌清单](../tests/fixtures/inventory/card-coverage.md) 的 559/559 指可直接打出的
原生日志卡牌均有定义匹配的成功原生出牌；四张原生不可打出的牌保留限制。
[遗物清单](../tests/fixtures/inventory/relic-coverage.md) 的 224/224 指各原始遗物有
对应接口／效果证据。这些数字不能作为任意升级、触发和组合均可求解的完成率。

每批提交并推送代码与对应证据，只运行相关检查。离线候选先通过完整状态／RNG
复演，找到可评估的改进后再花时间做新原生局；模型败局不冒充“不可能获胜”。
全量回归留给发布关口或公共机制的大范围修改；搜索预算是软时限，不保证总响应时长。
