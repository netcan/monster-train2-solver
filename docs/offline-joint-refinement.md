# 离线两步联合筛选

`FixtureTools improve-pairs` 在单步候选后增加最多32个第二次出牌候选，另保留
第二步结束回合。宽度按即时局面评分排序，时间／256步／迭代次数均有上限。
这是对完整败局的局部路线调查，不是最优解搜索，也不改变玩家面板的预算或策略。

```powershell
dotnet src/FixtureTools/bin/Release/net8.0/FixtureTools.dll improve-pairs `
  <native.mt2f> <verified-prediction.mt2f> <new-output.mt2f> 180000 4 20 8
```

参数依次是原生档案、绑定其SHA256的完整模型路线、新输出、软预算毫秒、
最多迭代次数、起始输入索引和第二步宽度0..32。不会覆盖已有方案或拒绝分支。
宽度0沿用单步筛选。每一步均从模型自己的父状态执行，不借用原生中间快照。
一条完整路线达到更好结果才会保留；导出前仍从原生初始局面独立复演整个方案，
核对完整后继、预测、终局和RNG。失败或超时的半条路线不会作为改进导出。
生成的不支持分支同样需要独立从初始局面重现，才能请求原生组件观察。

验证记录（2026-10-26）：自然Covenant3第六战v8，从输入20开始，单次迭代、
宽度0与原单步工具的33输入输出逐字节一致，SHA256
`6d9d14e6ff374a2cdcecad1cc68e69712869bad6f754e0ef4804c50481a64a6c`。
宽度8的180秒运行尝试118条路线（117条完整），其中105条联合候选，一条联合
候选被接受；两次改进后34输入仍败。最终独立复演通过，总耗时196.13秒，
包含导出校验；不宣称此样本比单步筛选更快。宽度33在读取档案前拒绝，
已有输出保护经原文件SHA256复核通过。尚未把联合筛选记为原生胜局。
