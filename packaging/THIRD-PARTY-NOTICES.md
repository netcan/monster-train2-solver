# Third-party runtime

The macOS package includes an unmodified official BepInEx 5.4.23.5 archive:

- Release and source: https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
- Runtime archive: `BepInEx_macos_universal_5.4.23.5.zip`
- SHA256: `01c2ae782eb016dfd6c345a18dbd2dcafffb3d9d318449d6486689f426b4a323`
- BepInEx license is included as `licenses/BepInEx-LICENSE.txt`.
- Upstream dependencies and licenses: https://github.com/BepInEx/BepInEx/tree/v5.4.23.5
- UnityDoorstop source: https://github.com/NeighTools/UnityDoorstop/tree/v4.5.0

Game assemblies, game assets, saves and development probe executables are not
redistributed. Newtonsoft.Json and Unity libraries are supplied by the installed
game. This advisor does not require Trainworks Reloaded or a separate .NET SDK.
